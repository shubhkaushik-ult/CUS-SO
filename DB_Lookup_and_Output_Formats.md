# Direct DB Lookup & Output Formats Documentation

This document explains the database queries used for direct lookup without the ECOM sheet, and clarifies the output file formats generated by the automation pipeline.

---

## 1. Direct Database Queries Used

### A. Direct SKU & Lot Lookup Query (`_DB_SKU_LOOKUP_QUERY`)
Fetches `sku_id`, `sku_name`, `lot_id`, and `city_id` using the FSN code and City ID:

```sql
SELECT DISTINCT
    peim.fsnCode           AS fsn,
    s.Id                   AS sku_id,
    s.Name                 AS sku_name,
    peim.lotWeightId       AS lot_id,
    peim.cityId            AS city_id
FROM asgard.Sku s
JOIN vormir.ProductExternalInternalMapping peim
    ON peim.skuId = s.Id
WHERE s.Deleted IN (0, 1)
  AND peim.cityId = %(city_id)s
  AND peim.fsnCode IN %(fsn_list)s;
```


---

### B. Customer Contact Lookup Query (`_DB_CONTACT_BY_NAME_QUERY`)
Fetches buyer/warehouse `ContactNumber` from `asgard.Customer`:

```sql
SELECT 
    Name, 
    ContactNumber 
FROM asgard.Customer 
WHERE CityId = %(city_id)s
  AND Name IN %(name_list)s;
```

#### Fuzzy Fallback Query (if exact name match fails):
```sql
SELECT 
    Name, 
    ContactNumber 
FROM asgard.Customer 
WHERE CityId = %(city_id)s 
  AND Name LIKE %(prefix)s 
LIMIT 1;
```

## 2. Output File Formats (Both Formats Provided)

The system automatically generates **BOTH** the standard GRO SO format and the **Institutional format** simultaneously when you run the process.

### Format 1: Standard GRO SO CSV (`<City> XD SO <Date>.csv`)
Contains all 16 standard columns:
1. `customer_contact_number(req)`
2. `NC ID`
3. `NC Name`
4. `QTY`
5. `Date`
6. `lot weight ID`
7. `ordering_mode(optional)` (Set to `"DELIVERY"`)
8. `cancelled (optional)By default should be 0` (Set to `0`)
9. `purchaseOrder`
10. `Sales Price` (Set to `1`)
11. `DELIVERY_CHARGE(opt)`
12. `CITY_ID(req)`
13. `sale_order_id(optional- leave empty)`
14. `sub_type (optional- leave empty)` (Set to `1`)
15. `CategoryId (if empty then default is 1)` (Set to `4`)
16. `grocerFlow`

---

### Format 2: Institutional Format CSV (`<City> XD SO <Date> (Institution).csv`)
Contains the 15 institutional format columns:
1. `customer_contact_number(req)`
2. `sku_id(req)`
3. `NC NAME`
4. `quantity(req)`
5. `delivery_date(DD-MM-YYYY)`
6. `lot_id(req)`
7. `ordering_mode(optional)` (Set to `1`)
8. `cancelled(optional)` (Set to `0`)
9. `purchaseOrder`
10. `Sales Price` (Set to `1`)
11. `DELIVERY_CHARGE(opt)`
12. `sale_order_id(optional)`
13. `sub_type(optional)` (Set to `1`)
14. `skuTypeId` (Set to `1`)
15. `CustomerId`
